# 두근분석소 설치용 웹앱 패키지

이 폴더는 안드로이드와 아이폰 홈 화면에 설치할 수 있도록 준비한 PWA(웹앱)입니다.

## 중요한 점
- 이 파일만 휴대폰에 복사해서는 설치되지 않습니다. 먼저 HTTPS를 지원하는 웹 호스팅에 폴더 안의 파일들을 올려야 합니다.
- 업로드 후 생성된 HTTPS 주소를 휴대폰에서 열어 설치합니다.
- 앱 자체 분석은 현재 브라우저 안에서 동작합니다. 실제 AI 서버 연결은 포함되어 있지 않습니다.
- 이 패키지는 앱스토어/구글 플레이 등록용 네이티브 앱이 아니라 홈 화면 설치용 웹앱입니다.

## 업로드할 파일
폴더 안의 모든 파일과 `icons` 폴더를 그대로 업로드하세요.
`index.html`, `manifest.webmanifest`, `sw.js`, `icons/`가 같은 위치에 있어야 합니다.

## 안드로이드 설치
1. 휴대폰 Chrome에서 업로드된 HTTPS 주소를 엽니다.
2. 메뉴(⋮)를 누릅니다.
3. '앱 설치' 또는 '홈 화면에 추가'를 선택합니다.

## 아이폰 설치
1. Safari에서 업로드된 HTTPS 주소를 엽니다.
2. 공유 버튼을 누릅니다.
3. '홈 화면에 추가'를 선택합니다.
4. '웹 앱으로 열기' 옵션이 보이면 켜고 '추가'를 누릅니다.

## 개인정보
사연은 외부 서버로 보내지 않도록 구현되어 있습니다. 사용자가 입력한 내용은 결과 화면에서 지울 수 있으며, 새로고침하면 결과가 사라집니다. 단, 이 안내는 현재 코드 동작에 대한 설명이며 사용자가 직접 복사/공유하거나 기기·브라우저가 별도 기록하는 경우까지 통제하지는 않습니다.
